# [ENFC]ExriconNiour's FoodsCraft

A food mod that adds some desserts to Minecraft.

## Features
- Adds desserts like cakes, pies, cookies, and ice cream.
- Most items can be crafted in the crafting table.
- Supports both Chinese and English.

## Supported Versions
- Minecraft 1.21.1
- Forge

## Author
ExriconNiour

## Source Code
